## Open limits

- **Snapshot:** active branches and dirty files changed while this ran. Re-run the defer check before any deletion.
- **Defer scope:** `apps/mobile`, `infra/relay`, `scripts` and non-provider packages never get `defer` by the rule. The Note column flags such items when a branch changes the file.
- **Import hits** are text matches, not a type-aware reference search. Dynamic loads by path or string (as with `crashWorker.ts`) can hide from both knip and this check.
- **Catalog entries** in [pnpm-workspace.yaml](../pnpm-workspace.yaml): removal edits the workspace file and can change `pnpm-lock.yaml`. Do that in a separate, reviewed change.
- **Mobile and relay:** this scan did not build or run `apps/mobile` or `infra/relay`. Expo and Cloudflare loaders can use exports by name.
- **Not checked:** unused types (rule is off), unused class members, and the `knip:production` profile.

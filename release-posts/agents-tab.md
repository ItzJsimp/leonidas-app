# Build your agent team in one place

The new **Agents** page replaces the old Subagents page and the Helpers tab in Library. It has three tabs: **Team**, **Runs** and **Starters**.

## Team: every agent, one list

Team lists each agent file from your AIOS and your open project. Each row shows a felt character, the agent name and a one-line job. The agent that can start other agents sits first, marked **Lead**.

Select an agent to see its model, effort, tools and instructions. You can edit, duplicate or delete it. Delete asks you to confirm. Every change goes to the same Markdown file that you can still edit by hand.

## Make an agent from one sentence

Select **New agent**. Step 1 asks for a name, a character and a model. Step 2 is a short chat: describe the job in one sentence and the creator drafts the instructions and tools. It uses a free model. Change the draft until it fits, then select **Create agent**. Effort, tools and skills sit in **Advanced**.

An agent with no chosen character gets the default helper.

## Runs: see what your agents did

Runs lists every agent run with its chat, model, cost, status and result. A run that another agent started links back to the run that started it.

## You stay in charge of spend

Cheap models start with no prompt. Any other model asks first and shows its engine, model and a rough cost. You can set a daily spend cap for agents in Settings. The default is $2 per day, with a warning at 80 percent.

## Starters

Starters has ready-made agents you can import into Team. If you already have the same agent, Import adds a numbered copy and never overwrites yours.

# Scribe model research, November 2026

Access date for every row: **2026-11-22**. Measured numbers come from [benchmarks-2026-11.md](./benchmarks-2026-11.md). "n/m" means not measured. "Secondary" means the source is a third-party page, because the vendor page is not readable without a browser. Treat a secondary price as unconfirmed until you read the vendor page.

Prices are in US dollars. Monthly cost uses 200 dictations a day for 30 days, at 0.70 minutes of audio each (4,200 minutes a month, from Jake's mean take of 105 words).

## Vendors named in the code and in memory

- **Grok (xAI): not in the code.** `rg -i "grok|xai|cerebras"` over `services/scribe-engine` finds nothing. The vendor is **Groq** (`api.groq.com`), a different company.
- **Cerebras: not in the code.** No Cerebras client or config field exists. Cerebras has no speech models, so it is a clean-up candidate only.
- **Deepgram: in the code.** It is the first speech provider (`config.rs`, `BackupConfig.speech`). Jake's real history shows 830 of 831 recorded takes served by `deepgram/nova-3`.

## Notes behind the rows

- **Deepgram privacy:** the [Model Improvement Partnership Program page](https://developers.deepgram.com/docs/the-deepgram-model-improvement-partnership-program) explains how Deepgram trains on data and how to opt out. Check the account setting before you send private audio.
- **Groq privacy:** the [Groq data page](https://console.groq.com/docs/your-data) says Groq keeps no input or output by default. It keeps data only for batch jobs, fine-tuning, or to protect the platform.
- **OpenAI:** the model page marks `gpt-4o-mini-transcribe` as Deprecated. Do not build on it.
- **Cerebras:** the trial needs a payment method. Ask Jake before any key is added.
- **Open ASR numbers:** the Parakeet and Moonshine accuracy figures come from the NVIDIA paper (arXiv 2509.14128) and the Moonshine v2 paper (arXiv 2602.12241), read through search summaries. Re-read the papers before you decide on a local model.
- **Local clean-up model:** no local Qwen or Gemma model was run, so the table has no row for it. A task card tracks it.
- **Table gaps:** `n/m` rows are open questions. Each one has a task card, listed in [benchmarks-2026-11.md](./benchmarks-2026-11.md).
